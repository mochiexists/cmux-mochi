# Stable, upstream, and clean validation matrix

This matrix records observable behavior against the accepted stable oracle, untouched upstream, and
the future clean build. It is evidence-indexed and intentionally rejects “looks good” as a result.

## Shared isolation contract

Every run uses a unique app tag, bundle or defaults identity, `HOME`, `CFFIXED_USER_HOME`, Unix
socket, fixture root, scratch root, DerivedData path, and evidence directory. Stable, upstream, and
clean runs may share fixture *content* copied from the same template, but never mutable paths or
processes.

## Evidence requirements

Each passing row links to machine-readable output where practical and to a short reviewed manual record
where macOS UI behavior cannot be fully automated. Screenshots or video never replace topology,
process, CLI, filesystem, event, or bundle evidence when those are available.
